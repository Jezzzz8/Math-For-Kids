# 🧮 Math For Kids

**A fun, interactive math practice game for children. Choose an operation (add, subtract, multiply, divide, or random), pick a difficulty level (Easy, Normal, Hard), and solve problems using the on-screen numpad or keyboard. Earn points for correct answers and see instant feedback with playful popups and sounds. Fully responsive – works on desktop, tablet, and mobile.**

---

## ✨ Features

- **5 Operations:** Addition, Subtraction, Multiplication, Division, Random
- **3 Difficulty Levels:** Easy, Normal, Hard
- **Interactive Numpad:** Tap or use keyboard (0‑9, Backspace, Enter)
- **Score Tracking:** +1 for correct, −1 for wrong (never below 0)
- **Instant Feedback:** Popup with icon + message, sound effects
- **Responsive Design:** Adapts to any screen size
- **Custom Icons:** Uses your own PNG images (replaceable)
